# One visible Save Path

Vince must see one place to save: VincePersonal. On VTA and taylorvalton, Windows Desktop, Documents, and Downloads redirect into `00_Inbox` capture subfolders (ADR 0010) so the old habit dies. This PC and OneDrive may remain as hidden sync pipes. We chose redirection over “pin and hope” because a visible Desktop will refill. The store decision stays ADR 0001.
