# Organizer names Documents; humans do not

Amended 2026-08-18 (ADR 0024).

Vince saves with any name. The Organizer is the only writer that applies the naming law. The old human enforcer (`YYYY-MM-DD_PREFIX_…_vNN` typed at save time) stays retired. It scored 27–38% because it punished people and code trees.

At digest the Organizer writes:

`YYYY-MM-DD_PREFIX_Readable Title_vNN.ext`

Date and prefix stay in the filename so SharePoint and Explorer look like one corpus. The title keeps spaces. Version is the same Document, not a collision (`Title-2` is a name clash). Secrets and code trees are never named.

Prefix, type, date, and version also live in the Document ledger (ADR 0024). The filename is the Explorer surface. The ledger is the identity SoT. The Vince Node holds a projection. The Correction Log is the lesson, not a regex Vince must satisfy.
