# Mail lives on day one; Outlook folders are not a second taxonomy

Documents and Mail start in the same live era. Day-one Mail means: attachments Vince files, or the Organizer files under a Correction, become Documents; message facts may project to the Vince Node. The first mail pass is the last 90 days; the rest of the mailbox follows after that writer is proven (ADR 0021). The Organizer does not invent a new Outlook folder tree. It moves a Message only when a Correction says so. A five-file document smoke still goes first in the same window so a mail flood cannot hide a broken writer.
