# Petra OneDrive maps onto VincePersonal

The Petra personal OneDrive numbered tree is a source, not a second home. Each source folder has one VincePersonal home:

| Source | Home |
|---|---|
| `00_INBOX` | `00_Inbox` |
| `01_Projects` | `01_Clients_Projects` |
| `02_Customers` | `01_Clients_Projects` |
| `03_Finance` | `02_Business_Ops` |
| `04_Operations` | `02_Business_Ops` |
| `05_HR` | `04_Admin` |
| `06_Marketing` | `03_Marketing_Creative` |
| `07_Admin` (minus code trees) | `04_Admin` |
| `08_Personal` | `05_Personal` |
| CursorInbox, Petra Desktop, Teams Chat Files, `OLD LAPTOP FILES`, root loose files | `00_Inbox` |

We do not add a seventh top-level folder. Customers are clients. Finance stays under Business Ops. HR is admin.
