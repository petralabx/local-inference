# Empty Petra folders are not a home

After a Petra OneDrive source folder is drained, it is removed or hidden. We do not leave `00_INBOX`–`09_Archive`, CursorInbox, or Desktop-under-OneDrive sitting empty. An empty folder that still looks like a save target will refill. The VincePersonal sync folder may remain as the OneDrive pipe to the one store. It is not a second library.
