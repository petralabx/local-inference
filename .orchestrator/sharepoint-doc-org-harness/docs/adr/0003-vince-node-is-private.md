# Vince Node is private inbound

Secondbrain, the graph, compilers, and ingest run for this project, but Document text and move facts live in a Vince Node. Vince, as himself, may toggle between that node and the rest of PLX under his own admin policies. The reverse is false: no other PLX person, and no agent he did not evoke, may read or write the node or its Documents. Installing the daily Organizer job is Vince evoking it. We reuse the platform we already built and refuse a company-wide index of VincePersonal.
